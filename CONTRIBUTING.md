# Contributing to AirDraw

Thank you for your interest in contributing to **AirDraw**!

## Development Setup

```bash
git clone https://github.com/<your-username>/airdrawing.git
cd airdrawing
npm install
npm run dev
```

## Verification Checks

Before opening a pull request, run:

```bash
npm run typecheck
npm test
npm run build
```

## Code of Conduct

Please adhere to our [Code of Conduct](CODE_OF_CONDUCT.md) in all interactions.
